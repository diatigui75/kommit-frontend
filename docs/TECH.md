# Stack technique

## Frontend

| Rôle                | Outil                    |
| ------------------- | ------------------------ |
| Bibliothèque UI     | React                    |
| Langage             | TypeScript (v6)          |
| Build               | Vite                     |
| Styles              | Tailwind                 |
| Composants          | shadcn/ui (avec Base UI) |
| Validation          | Zod                      |
| Requêtes serveur    | TanStack Query           |
| Routing             | React Router             |
| Tests unitaires     | Vitest                   |
| Tests de composants | React Testing Library    |
| Tests end-to-end    | Playwright               |

## Infra

| Rôle                 | Outil                   |
| -------------------- | ----------------------- |
| Hébergement frontend | Vercel                  |
| Hébergement backend  | Render                  |
| Code et CI/CD        | GitHub / GitHub Actions |
| Gestion de projet    | Notion                  |
